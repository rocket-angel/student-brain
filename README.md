# Student Brain

The empty skeleton of your brain — the AI-Native Year.

This repo is deliberately empty. It is the SHAPE of a brain, not its contents:
the same tree the operator's own brain is built in, so that everything you are
given over the year lands where it belongs, and your skeleton grows into the
same structure hers has.

    db/founding/     how your brain's database is founded — the empty room,
                     the extensions, the whole schema, your configuration,
                     and the one line that verifies it                (month 1)
    db/organ/        the walls your brain enforces, and the walk that proves
                     them — the suite you run against your own brain    (month 1)
    db/organ/plants/ deliberate sabotage: each file breaks one real thing, so
                     you can watch the checks catch it by name          (month 1)
    organ/           the commands your brain runs on — what reads your folder,
                     what distils it, what answers you, and the checkup (month 1)
    identity/        who your brain is when it answers you              (month 1)

Later months fill this same tree further. Nothing is ever moved to make room.

## How files arrive

Every file is given to you inside the course, with the lesson that explains it
and the record of what was run to prove it works. Nothing lands in this repo
before you understand it. That is why the folders start empty.

## Getting started

1. Download this repo: Code → Download ZIP (or clone it).
2. Unzip it as `~/brain` — every path in the course is relative to this folder.
3. Open lesson 1 and build.

Before the organ runs (lesson 19 onwards) you will need Python 3.11+ and a
virtual environment. The course walks you through it.

Nothing here spends money or touches a database until the course gives you the
files and you run them with your own keys — and your spend cap goes on
(lesson 41) before the first lesson that spends.
