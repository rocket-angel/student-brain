# Student Brain

The empty skeleton of your brain — the AI-Native Year.

This repo is deliberately empty. It is the SHAPE of a brain, not its contents:
the same tree the operator's own brain is built in, so that everything you are
given over the year lands where it belongs, and your skeleton grows into the
same structure hers has.

## How files arrive

Every file is given to you inside the course, with the lesson that explains it
and the record of what was run to prove it works. Nothing lands in this repo
before you understand it. That is why the folders start empty.

## Getting started

1. Download this repo: Code → Download ZIP (or clone it).
2. Unzip it as `~/brain` — every path in the course is relative to this folder.
3. Open lesson 1 and build.

Nothing here spends money or touches a database until the course gives you the
files and you run them with your own keys and your spend.
